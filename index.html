Intro

Hi, I'm Mubarak, a Mechanical Engineering student at Osun State University, Nigeria. I'm building a career at the intersection of Mechanical Engineering, Data Analytics, and Data Science, using data and machine learning to understand machine performance and improve engineering decisions.

I work with SQL, Python, Statistics, Power BI, and Excel for data analysis and visualization, alongside SOLIDWORKS for CAD and mechanical design. I've applied machine learning to predict the remaining useful life of jet engines. I'm especially interested in Formula 1 telemetry, aerospace systems, EV battery analytics, and Industrial IoT.

See how I put this into practice in my projects.

F1 RACE DASHBOARD

In this project, I built an end-to-end race analytics dashboard to analyze lap-by-lap pace gaps, tyre degradation trends, and track evolution using real-world F1 race data. The application extracts raw telemetry using the FastF1 API, filters out pit lane noise and missing timestamps, and applies linear regression to quantify tyre degradation rates across stints. I also accounted for real-world variables—discovering how a drying track in Monaco 2022 hid tyre wear because lap times improved as grip increased, whereas Bahrain 2022 showed clear, steady tyre degradation on a dry track. JET ENGINE RUL PREDICTION

This project uses machine learning to predict the Remaining Useful Life (RUL) of jet engines from NASA's simulated turbofan sensor data. I analyzed sensor trends over each engine's life, engineered features such as a rolling average and a temperature difference, and trained Linear Regression and Random Forest models to estimate the flight cycles left before failure.

About

My Engineering Journey

Alongside my academic studies, I apply my skills through hands-on technical projects. One of my completed projects involved developing a machine learning workflow to predict the remaining useful life (RUL) of jet engines using NASA's C-MAPSS dataset.
